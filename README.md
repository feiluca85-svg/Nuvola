# Nuvola WP8 WebApp (PWA)

Web App minimale in stile Windows Phone 8 per accedere rapidamente al registro elettronico Nuvola di Madisoft.

## Come caricare il progetto su GitHub:

1. Crea un nuovo repository pubblico su GitHub chiamato `nuvola-wp8` (o il nome che preferisci).
2. Nel terminale nella cartella del progetto (`/Users/ilalu/Desktop/Nuvola`):
   ```bash
   git remote add origin https://github.com/TUO-UTENTE/nuvola-wp8.git
   git branch -M main
   git push -u origin main
   ```
3. Su GitHub, vai nelle impostazioni del repository (**Settings**) -> **Pages**.
4. Sotto **Build and deployment**, seleziona il ramo `main` e clicca su **Save**.
5. Attendi circa 1 minuto: GitHub ti fornirà un link pubblico HTTPS tipo `https://tuo-utente.github.io/nuvola-wp8/`.

## Come installarla sul telefono Android:

1. Apri **Google Chrome** sul tuo telefono Android e vai sul tuo link `https://tuo-utente.github.io/nuvola-wp8/`.
2. Chrome riconoscerà automaticamente la PWA: vedrai comparire un banner in basso **"Aggiungi a Schermata Home"** o **"Installa app"**.
3. Se non compare subito, clicca sui 3 pallini in alto a destra su Chrome e seleziona **"Aggiungi a schermata Home"** (o **"Installa applicazione"**).
4. Fatto! Sul tuo telefono apparirà l'icona quadrata rossa/magenta in pieno stile **Windows Phone 8**. Cliccandola si aprirà Nuvola direttamente!
